# Gmail Filter Reference — Keep Inbox Clean Going Forward

After running the bulk organizer script, create these Gmail filters to automatically sort future emails.

**How to create a filter:**
Gmail → Settings (gear icon) → See all settings → Filters and Blocked Addresses → Create a new filter

---

## Tips

- When creating each filter, check **"Also apply filter to matching conversations"** to retroactively apply it.
- For noise senders, you can also check **"Delete it"** instead of just archiving.
- Filter #1 (Square) is the highest-impact single filter — handles the most volume.
- Team Reports (#5) and Client Comms (#6) intentionally stay in the inbox so they get reviewed.
